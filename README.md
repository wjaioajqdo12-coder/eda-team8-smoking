# 흡연자의 간 수치가 높은 건 담배 탓일까, 술 탓일까?

자료탐색방법론 기말 팀 프로젝트 · 8조 (이동규, 이하늘, 정형기)

## 자료
- 자료명: 국민건강보험공단_건강검진정보 (2023년)
- 제공기관: 국민건강보험공단
- 원출처: 공공데이터포털 https://www.data.go.kr/data/15007122/fileData.do (2026-11-17 기준 페이지 열리지 않음)
- 실제 다운로드 경로: https://www.gimi9.com/dataset/www-data-go-kr-data-filedata-15007122/ (공공데이터포털 사본)
- 다운로드 날짜: 2026-11-17
- 이용 조건: 이용허락범위 제한 없음
- 한 행의 의미: 2023년 건강검진을 받은 사람 1명 (무작위 추출 100만 명)
- `hc2023.zip`: 원본 파일 `국민건강보험공단_건강검진정보_2023.zip`의 이름만 영어로 바꾼 것 (내용 동일, CSV + 사용자 매뉴얼)

## 탐색 질문
1. 간 수치(감마지티피)는 어떻게 분포하고, 로그 변환을 하면 어떻게 달라지는가?
2. 흡연자의 간 수치가 비흡연자보다 높은가? 성별과 음주 여부로 나눠 봐도 같은가?
3. 시도별 흡연율 차이는 성별과 연령대로 나눠 봐도 유지되는가?

## 실행 순서
1. `00_데이터정리.ipynb`를 Google Colab에서 열고 런타임 → 모두 실행
   - 이 저장소에서 `hc2023.zip`을 자동으로 내려받아 `hc2023_clean.csv`를 만듭니다.
2. 질문별 노트북을 같은 세션에서 실행 (추가 예정)
